# 第 01 课：开发环境搭建

> 本课目标：把开发环境装好，并成功运行一次"示例模组"，看到 Minecraft 模组列表里出现你自己的模组。
>
> 前置知识：无。这是第一课，我们从头开始。

---

## 1.1 我们到底要装什么？

做 Forge 模组，本质上就是**用 Java 语言写程序**。所以我们需要三样东西：

| 工具 | 作用 | 生活中的类比 |
|---|---|---|
| **JDK 17**（Java 开发工具包） | 提供 Java 语言的编译器和运行环境 | 厨房和灶具——没有它做不了饭 |
| **IntelliJ IDEA**（社区版，免费） | 写代码用的编辑器（IDE） | 你的案板和菜刀——写代码的地方 |
| **Forge MDK**（模组开发套件） | Forge 官方提供的"模组工程模板" | 一份已经打好地基的房子图纸 |

> ⚠️ **版本警告**：Minecraft 1.20.1 必须使用 **JDK 17**。装 JDK 8 或 JDK 21 都会导致构建失败。版本不对是新手最常见的坑，没有之一。

---

## 1.2 第一步：安装 JDK 17

1. 打开浏览器，访问 Adoptium（一个免费、可靠的 JDK 发行版网站）：
   <https://adoptium.net/temurin/releases/?version=17>
2. 选择：Operating System = **Windows**，Architecture = **x64**，Package Type = **JDK**。
3. 下载 `.msi` 安装包，双击安装。
4. 安装过程中**务必勾选** "Set JAVA_HOME variable"（设置环境变量）这一项，其余保持默认。

### 验证安装

按下 `Win + R`，输入 `powershell` 回车，在打开的窗口中输入：

```powershell
java -version
```

如果看到类似下面的输出，说明安装成功：

```
openjdk version "17.0.x" 2024-xx-xx
OpenJDK Runtime Environment Temurin-17.0.x+x (build 17.0.x+x)
```

> 💡 **什么是环境变量？** 可以把它理解为"电脑的全局通讯录"。配置了 JAVA_HOME 之后，任何程序想找 Java 都能通过这本通讯录找到它。

---

## 1.3 第二步：安装 IntelliJ IDEA 社区版

1. 访问 <https://www.jetbrains.com/idea/download/>
2. 向下滚动，找到 **IntelliJ IDEA Community Edition**（社区版，免费），点击 Download。
   - ⚠️ 不要下错成旗舰版（Ultimate）的试用版，社区版完全够用。
3. 双击安装包，一路 Next 即可，建议勾选 "Create Desktop Shortcut"（创建桌面快捷方式）。

---

## 1.4 第三步：下载 Forge MDK

MDK = Mod Development Kit（模组开发套件），是 Forge 官方准备好的工程模板。

1. 访问 Forge 官方下载站：<https://files.minecraftforge.net/>
2. 左侧选择 Minecraft 版本 **1.20.1**。
3. 在右侧找到 **MDK** 按钮（不是 Installer！Installer 是给玩家装模组用的），点击下载一个 zip 文件，例如 `forge-1.20.1-47.2.0-mdk.zip`。
4. 把 zip 解压到一个**路径中不含中文和空格**的文件夹，例如：

   ```
   D:\ModDev\MyFirstMod
   ```

   > ⚠️ 路径里有中文或空格会导致 Gradle 构建报各种莫名其妙的错误。这是新手第二大坑。

解压后你会看到一堆文件，先认识几个重要的：

```
MyFirstMod/
├── build.gradle          ← 构建脚本（模块二会详细讲）
├── gradlew               ← Gradle 启动器（Windows 用 gradlew.bat）
├── settings.gradle
└── src/
    └── main/
        ├── java/         ← 你的 Java 代码放这里
        │   └── com/example/examplemod/ExampleMod.java   ← 示例模组主类
        └── resources/      ← 贴图、语言文件、配置放这里
            └── META-INF/mods.toml                        ← 模组信息文件
```

---

## 1.5 第四步：用 IDEA 打开工程并完成首次构建

1. 启动 IDEA，选择 **Open**，选中刚才解压的 `MyFirstMod` 文件夹，点确定。
2. IDEA 会自动识别这是一个 Gradle 工程，开始**首次构建**。右下角会有进度条。
   - 首次构建要下载 Minecraft、Forge 和大量依赖，**约 1GB**，视网速需要 10～60 分钟。
   - 如果下载很慢，属于正常现象，去喝杯水。模块二会教你配置国内镜像加速。
3. 构建完成后，打开右侧的 **Gradle** 面板（侧边栏大象图标 🐘），依次展开：

   ```
   Tasks → forgegradle runs → runClient
   ```

   双击 **runClient**，就会启动一个"开发版"的 Minecraft 客户端。

4. 进入游戏主界面后，点击 **Mods** 按钮——你应该能在列表里看到 **Example Mod**！

🎉 恭喜！看到这里，说明你的环境已经 100% 搭建成功了。

> 💡 **runClient 是什么？** 它是 Forge 帮你准备好的一个"开发专用启动器"，启动时会自动把你写的模组代码加载进游戏。你改代码 → 重新 runClient → 就能看到效果。

---

## 1.6 认识示例模组主类

用 IDEA 打开 `src/main/java/com/example/examplemod/ExampleMod.java`，先不用看懂每一行，只需找到这几处"眼熟"的地方：

```java
@Mod(ExampleMod.MODID)   // ← 这行告诉 Forge："我是一个模组"
public class ExampleMod {
    public static final String MODID = "examplemod";  // ← 模组的身份证号

    public ExampleMod() {
        // 构造函数：模组被加载时会执行这里的代码
    }
}
```

现在试着改一个字：把 `ExampleMod.java` 里 `LOGGER.info("HELLO ...")` 这类语句中的文字随便改一改，重新运行 runClient，看看游戏日志里是不是出现了你改的文字。

**这就是模组开发的日常循环：改代码 → 运行 → 看效果。**

---

## 1.7 本课小结

- 开发 Forge 模组需要：JDK 17 + IntelliJ IDEA 社区版 + Forge MDK。
- JDK 版本必须是 17；工程路径不能含中文和空格。
- 双击 Gradle 面板里的 `runClient` 可以启动带模组的开发版游戏。
- `@Mod` 注解是模组的"身份证"，MODID 是模组的唯一编号。

## 1.8 配套练习

> 答案见本模块 `答案/模块一答案与解析.md`，先独立完成再对照。

**基础题**

1. 在 PowerShell 中用什么命令验证 Java 安装成功？成功时应看到什么关键信息？
2. 为什么不能把工程放在 `D:\我的模组\` 这样的路径下？
3. 在 Gradle 面板中，启动开发版游戏的任务叫什么名字？

**提高题**

4. 打开 `mods.toml`（在 `src/main/resources/META-INF/` 下），找到 `modId="examplemod"` 这一行，把它改成 `modId="mycoolmod"`，同时把 `ExampleMod.java` 里的 `MODID` 也改成 `"mycoolmod"`，重新运行 runClient，观察 Mods 列表里的变化。记下你一共改了哪几处。
5. 思考题：如果 JDK 装成了 21 版本，构建时大概率会失败。你觉得为什么 Minecraft 模组开发对 Java 版本要求这么严格？（提示：Java 程序运行需要"运行时环境"的支持）
