# 第 06 课：注册你的第一个物品和方块

> 本课目标：掌握 Forge 的注册系统（DeferredRegister），添加一个自定义物品和一个自定义方块，并在游戏里拿到它们。
>
> 前置知识：第 05 课（模组主类已搭好）。

---

## 6.1 什么是"注册"？

Minecraft 里每种物品、方块、生物都有一个"身份"（命名空间 ID，如 `minecraft:diamond_sword`）。游戏启动时会制作一本**花名册（Registry）**，所有内容必须登记在册，游戏才认识它。

Forge 提供了一个方便的登记工具：**DeferredRegister**（延迟注册器）。它会替你在正确的生命周期阶段，把你的内容登记进花名册。

> 💡 **类比**：DeferredRegister 像学校的"新生登记表"。开学时（游戏启动）学校统一按登记表给新生（你的物品）注册学籍。你只要提前把名字填进表，剩下的交给学校。

## 6.2 注册第一个物品

### 第 1 步：创建物品注册类

在 `com.mycooldev.mycoolmod` 包下新建类 `ModItems`：

```java
package com.mycooldev.mycoolmod;

import net.minecraft.world.item.Item;
import net.minecraftforge.eventbus.api.IEventBus;
import net.minecraftforge.registries.DeferredRegister;
import net.minecraftforge.registries.ForgeRegistries;
import net.minecraftforge.registries.RegistryObject;

public class ModItems {

    // ① 创建"物品登记表"。参数告诉它：登记到物品花名册、属于哪个模组
    public static final DeferredRegister<Item> ITEMS =
            DeferredRegister.create(ForgeRegistries.ITEMS, MyCoolMod.MODID);

    // ② 在表上登记一个物品：注册名 "ruby"（红宝石）
    public static final RegistryObject<Item> RUBY =
            ITEMS.register("ruby", () -> new Item(new Item.Properties()));

    // ③ 提供一个方法，把登记表挂到事件总线上（主类会调用它）
    public static void register(IEventBus eventBus) {
        ITEMS.register(eventBus);
    }
}
```

逐行拆解最容易晕的第 ② 步：

```java
public static final RegistryObject<Item> RUBY =
        ITEMS.register("ruby", () -> new Item(new Item.Properties()));
//                     ↑                              ↑
//              注册名（全小写）          一个"制造配方"：到时候照此造出物品
```

- `"ruby"` 是物品的**注册名**（不是显示名！显示名下一课用语言文件做）。规范：全小写，用下划线分词。
- `() -> new Item(...)` 是 **Lambda 表达式**（第 03 课方法的简写形式），读作"一个无参数、返回新 Item 的方法"。它告诉登记表："需要造这个物品时，就 `new Item(...)`。"
- `new Item.Properties()` 是物品的**属性配置**，现在用默认的，后面会往里加东西（比如设置最大堆叠数）。

### 第 2 步：在主类里挂接登记表

修改主类构造方法：

```java
public MyCoolMod() {
    IEventBus modEventBus = FMLJavaModLoadingContext.get().getModEventBus();

    ModItems.register(modEventBus);   // ← 新增：把物品登记表挂到总线上
}
```

### 第 3 步：运行并获取物品

运行 `runClient`，创建一个**创造模式**世界，按 `T` 打开聊天栏，输入：

```
/give @p mycoolmod:ruby
```

你的物品就出现在背包里了！它现在还没有贴图（显示为紫黑色方块）和名字——别急，那是第 07 课的事。

> 💡 `mycoolmod:ruby` 的结构是 `模组ID:注册名`。`minecraft:diamond` 也是同样结构。

## 6.3 注册第一个方块

方块比物品麻烦一点，因为**方块要注册两次**：一次作为"方块"（世界里的实体），一次作为"物品"（背包里能拿的形态）。

在包下新建 `ModBlocks`：

```java
package com.mycooldev.mycoolmod;

import net.minecraft.world.item.BlockItem;
import net.minecraft.world.item.Item;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.Blocks;
import net.minecraft.world.level.block.state.BlockBehaviour;
import net.minecraftforge.eventbus.api.IEventBus;
import net.minecraftforge.registries.DeferredRegister;
import net.minecraftforge.registries.ForgeRegistries;
import net.minecraftforge.registries.RegistryObject;

import java.util.function.Supplier;

public class ModBlocks {

    // ① 方块登记表
    public static final DeferredRegister<Block> BLOCKS =
            DeferredRegister.create(ForgeRegistries.BLOCKS, MyCoolMod.MODID);

    // ② 注册方块：红宝石块，硬度 5、爆炸抗性 6、需要铁质以上工具挖掘
    public static final RegistryObject<Block> RUBY_BLOCK = registerBlock("ruby_block",
            () -> new Block(BlockBehaviour.Properties.copy(Blocks.IRON_BLOCK)   // 复制铁块的基础属性
                    .strength(5.0f, 6.0f)        // 硬度、爆炸抗性
                    .requiresCorrectToolForDrops()));  // 需要合适工具才掉落

    // ③ 辅助方法：一次调用同时注册"方块"和"方块对应的物品"
    private static <T extends Block> RegistryObject<T> registerBlock(
            String name, Supplier<T> blockSupplier) {

        RegistryObject<T> block = BLOCKS.register(name, blockSupplier);
        // 注册方块物品：背包里那一格就是它
        ModItems.ITEMS.register(name, () -> new BlockItem(block.get(), new Item.Properties()));
        return block;
    }

    public static void register(IEventBus eventBus) {
        BLOCKS.register(eventBus);
    }
}
```

主类里再加一行：

```java
public MyCoolMod() {
    IEventBus modEventBus = FMLJavaModLoadingContext.get().getModEventBus();

    ModItems.register(modEventBus);
    ModBlocks.register(modEventBus);   // ← 新增
}
```

> 💡 `registerBlock` 里的 `<T extends Block>` 是**泛型**（模块二第 03 课详解）。现在只需理解：这个辅助方法能用于任何种类的方块，不用每种方块都重写一遍注册逻辑——这正是第 03 课"方法复用"思想的升级版。

> ⚠️ **注意顺序**：`ModItems.register()` 必须在 `ModBlocks.register()` **之前**调用，因为注册方块物品时要用到物品登记表 ITEMS。

运行游戏，`/give @p mycoolmod:ruby_block`，你就得到了红宝石块！

## 6.4 看懂属性配置（Properties）

物品和方块都有大量可配置的属性，全部通过"链式调用"设置（每个方法返回自己，所以可以一路点下去）：

```java
// 物品属性示例
new Item.Properties()
        .stacksTo(16)            // 最大堆叠 16（默认 64）
        .durability(100)         // 耐久度 100
        .fireResistant();        // 防火（掉岩浆里不烧毁）

// 方块属性示例
BlockBehaviour.Properties.copy(Blocks.STONE)  // 以石头为模板
        .strength(3.0f)          // 硬度（影响挖掘时间）
        .lightLevel(state -> 15) // 发光等级 15（像火把一样亮）
        .sound(SoundType.GLASS); // 玻璃音效
```

> ⚠️ 注意 `strength(5.0f)` 里的 `f`：表示这是一个 `float` 类型的小数，这是 Java 语法要求。

## 6.5 本课小结

- 游戏里的所有内容必须先"注册"才能被识别；Forge 用 `DeferredRegister` 帮我们注册。
- 注册三件套：创建 DeferredRegister → 用 `.register("名字", 制造配方)` 登记 → 在主类把登记表挂到事件总线。
- 方块需要同时注册"方块本身"和"方块物品（BlockItem）"。
- 注册名必须全小写；游戏里用 `/give @p 模组ID:注册名` 获取。
- 物品/方块的行为通过 `Properties` 链式配置。
