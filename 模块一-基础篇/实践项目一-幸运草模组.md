# 实践项目一：幸运草模组（Lucky Clover）

> 综合运用模块一全部知识，独立完成一个完整的小模组。
> **先独立完成，再翻开 `答案/模块一答案与解析.md` 对照。**

---

## 项目背景

我们来做一个"幸运草"模组：玩家可以在世界里找到（或用指令获得）一株**幸运草方块**和一颗**四叶草物品**，为后续学习（右键触发随机事件等高级功能）打下基础。本模块只要求完成"静态内容"部分。

## 需求清单

### 1. 模组基本信息

- 模组 ID：`luckyclover`
- 包名：`com.lucky.luckyclover`
- 显示名：Lucky Clover（语言文件里中文显示"幸运草"）
- 版本：1.0.0，作者：你的名字
- 主类构造方法打印日志："幸运草模组加载完毕！"

### 2. 物品：四叶草

- 注册名：`four_leaf_clover`
- 中文名：四叶草；英文名：Four-leaf Clover
- 最大堆叠：16
- 创造模式位置："原材料"（Ingredients）标签页
- 自定义贴图（16×16，画一片绿色四叶草即可，不要求美观）

### 3. 方块：幸运草方块

- 注册名：`lucky_clover_block`
- 中文名：幸运草方块；英文名：Lucky Clover Block
- 以原版 `Blocks.GRASS_BLOCK` 的属性为模板（提示：`BlockBehaviour.Properties.copy(...)`）
- 发光等级：7
- 创造模式位置："自然方块"（Natural Blocks）标签页
- 自定义贴图，六个面共用一张
- 能在背包里以物品形态持有（BlockItem）

### 4. 验收标准

- [ ] `runClient` 启动无报错，Mods 列表显示 "Lucky Clover"
- [ ] 控制台能看到日志"幸运草模组加载完毕！"
- [ ] `/give @p luckyclover:four_leaf_clover` 能获得四叶草，显示中文名和贴图
- [ ] `/give @p luckyclover:lucky_clover_block` 能获得幸运草方块，放置后发光
- [ ] 两个内容都能在创造模式对应标签页找到
- [ ] 游戏语言切换为英文后，显示英文名

## 提示

- 步骤顺序建议：主类 → ModItems → ModBlocks → 语言文件 → 模型/贴图 → 创造物品栏事件。
- 自然方块标签页的常量名是 `CreativeModeTabs.NATURAL_BLOCKS`。
- 发光属性：`BlockBehaviour.Properties` 的 `.lightLevel(state -> 7)`。
- 卡住了先回看第 06、07 课；还卡住再看答案，但**一定要自己敲一遍**。
