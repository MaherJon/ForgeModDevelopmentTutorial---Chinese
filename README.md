# Forge 模组开发教程：从入门到精通

> 一套为**零编程基础**的学习者编写的 Minecraft Forge 模组开发中文教程。
> 目标版本：Minecraft **1.20.1** + Forge **47.x** + Java **17**。

---

## 这套教程适合谁

- 完全没有写过代码，想从零开始学做 Minecraft 模组的人；
- 玩过很多模组，好奇"模组到底是怎么做出来的"的玩家；
- 想顺便学一门编程语言（Java）的学习者。

只要你有一台能运行 Minecraft 的电脑，就可以开始。不需要任何编程经验。

## 学习路线总览


## 使用说明

1. **顺序学习**：每一课都假设你已经掌握了前面的内容，请不要跳课（已有 Java 基础者可快速浏览第 02～04 课）。
2. **每课结构**：知识点讲解 → 代码示例 → 本课小结 → 配套练习。
3. **练习与答案分离**：每课末尾的练习题，答案统一放在本模块的 `答案` 文件夹中。**先自己做，再看答案。**
4. **实践项目**：每个模块学完后，先独立完成实践项目，再对照参考答案检查。
5. **动手！动手！动手！** 看十遍不如敲一遍。教程里所有代码都请亲自输入，不要复制粘贴。

## 开始前你需要准备

- 一台 Windows / macOS / Linux 电脑（本教程以 Windows 为例）；
- 至少 8GB 内存（推荐 16GB）；
- 稳定的网络（首次构建需要下载约 1GB 的开发资源）；
- 一颗不怕报错的心 ❤（报错是程序员每天的家常便饭）。
